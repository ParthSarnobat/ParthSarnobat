## 🚀 Featured Project

### [KaggleMind](https://github.com/ParthSarnobat/KaggleMind) — Multi-Agent LLM Pipeline for Kaggle Competitions

> A personal multi-agent AI framework designed to act as an autonomous co-pilot for ML competitions.

**Phase 1 — Deep Research Agent**: Scrapes Kaggle competition URLs and generates a ground-truth dossier covering data schema, evaluation metrics, and competition rules to prevent LLM hallucinations.

**Phase 2 — Strategy War Room**: An interactive ML Architect agent that brainstorms cross-validation configurations, feature engineering pipelines, and class imbalance strategies — with live Mermaid.js flowchart generation.

**Phase 3 — Code Co-Pilot**: Parses uploaded `.py` scripts and `.ipynb` notebooks, reads the live strategy history from Phase 2, and identifies deviations from the planned architecture.

`LangChain` `Gemini` `Streamlit` `Multi-Agent` `Prompt Engineering`
